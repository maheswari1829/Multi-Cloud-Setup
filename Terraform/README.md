# 🚀 About Terraform

Terraform is an Infrastructure as Code (IaC) tool used to automate cloud infrastructure provisioning across multiple cloud providers.

This section contains:
- AWS Terraform
- Azure Terraform
- GCP Terraform
- Modules
- Remote Backends
- Real-Time Projects
- Multi-Cloud Infrastructure

---

# 📂 Terraform Cloud Providers

| Provider | Purpose |
|---|---|
| AWS | Infrastructure Automation |
| Azure | Cloud Resource Provisioning |
| GCP | Cloud Infrastructure |
| Kubernetes | Cluster Resources |
